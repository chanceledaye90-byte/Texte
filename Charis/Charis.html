1. PRÉSENTATION DU GROUPE ET ORGANISATION INTERNE

[span_0](start_span)

Conformément aux exigences pédagogiques, notre équipe est constituée de 5 à 6 étudiants de l'IFRI issus de filières différentes[span_0](end_span). [span_1](start_span)Cette mixité permet de simuler un environnement professionnel et de croiser les compétences en génie logiciel et développement d'applications[span_1](end_span).

1.1 Démarche de travail suivie

[span_2](start_span)

Pour mener à bien ce projet dans le délai strict de 10 jours, le groupe a adopté une méthodologie agile simplifiée[span_2](end_span). [span_3](start_span)Nous avons découpé les 10 jours en 3 phases majeures[span_3](end_span):

    [span_4](start_span)
  1. Jours 1 à 3 (Conception & Architecture) : Analyse du cahier des charges, modélisation de la base de données relationnelle et création des maquettes HTML/CSS d'interface[span_4](end_span).
    2. [span_5](start_span)
  2. Jours 4 à 8 (Développement intensif) : Initialisation du projet sous Django, codage des vues métiers, implémentation du moteur de matching et synchronisation continue via Git[span_5](end_span).
    3. [span_6](start_span)
  3. Jours 9 à 10 (Tests & Déploiement) : Phase de test des cas d'utilisation (connexions, formulaires, messagerie), correction des bugs, rédaction de la documentation finale et déploiement[span_6](end_span).

2. SPÉCIFICATIONS FONCTIONNELLES OBLIGATOIRES

[span_13](start_span)

L'application fournit une interface unifiée de mise en correspondance pour les étudiants de l'IFRI selon trois axes incontournables[span_13](end_span):

2.1 Gestion des profils et sécurité

    [span_14](start_span)
  • Inscription & Unicité : Formulaire requérant Nom, Prénom, Téléphone, E-mail et Mot de passe[span_14](end_span). [span_15](start_span)Le système rejette toute inscription si l'e-mail ou le numéro de téléphone est déjà présent dans la base MySQL[span_15](end_span).
    • [span_16](start_span)
  • Authentification : Connexion sécurisée avec e-mail/téléphone et mot de passe hashé[span_16](end_span). [span_17](start_span)Gestion des erreurs de connexion et processus de réinitialisation[span_17](end_span).
    • [span_18](start_span)
  • Profil utilisateur : Modifiable en tout temps[span_18](end_span). [span_19](start_span)Il inclut la photo (facultative), la filière, le niveau, les points forts (compétences maîtrisées), les points faibles (matières à améliorer) et les disponibilités[span_19](end_span).

2.2 Moteur de Matching et Messagerie

    [span_20](start_span)
  • Offres et Demandes : Publication d'annonces de mentorat précisant la matière, la plage horaire et le format (présentiel, en ligne ou hybride)[span_20](end_span).
    • [span_21](start_span)
  • Algorithme de calcul : Le serveur calcule automatiquement un score d'affinité basé sur la concordance croisée "Points forts du mentor / Points faibles du mentoré", la superposition des horaires et la proximité de filière[span_21](end_span). [span_22](start_span)Les résultats s'affichent sous forme de liste claire triée par score de compatibilité[span_22](end_span).
    • [span_23](start_span)
  • Messagerie textuelle : Canal d'échange instantané entre les binômes validés, équipé de notifications en temps réel lors de l'envoi de messages et d'un historique complet persistant[span_23](end_span).

3. CONCEPTION TECHNIQUE (STRUCTURE ET BASE DE DONNÉES)

3.1 Structure du projet et architecture

[span_24](start_span)

Le projet adopte une architecture client-serveur basée sur le patron de conception MVT (Modèle-Vue-Template) natif de Django, assurant une séparation hermétique entre la couche de données, la logique métier et l'affichage utilisateur[span_24](end_span).

3.2 Modèle de Données (Schéma de la base de données)

La base de données relationnelle s'articule autour des tables principales suivantes :

    [span_25](start_span)
  • Utilisateur (User) : Contient l'identifiant unique, le nom, le prénom, l'e-mail unique, le numéro de téléphone unique, le mot de passe hashé, la filière et le niveau d'études[span_25](end_span).
    • [span_26](start_span)
  • Matiere / Competence : Liste référentielle des matières enseignées à l'IFRI[span_26](end_span).
    • [span_27](start_span)
  • Profil_Matiere : Table d'association qualifiant le niveau de l'utilisateur sur une matière (Type : "Point Fort" ou "Point Faible")[span_27](end_span).
    • [span_28](start_span)
  • Annonce (Offre/Demande) : Stocke l'auteur, la matière concernée, le type d'annonce, les disponibilités associées et le format de l'échange[span_28](end_span).
    • [span_29](start_span)
  • Message : Enregistre l'expéditeur, le destinataire, le corps textuel du message et l'horodatage précis pour l'historique de la conversation[span_29](end_span).

5. INSTRUCTIONS DE DÉPLOIEMENT

[span_38](start_span)

Pour déployer et tester l'application localement ou sur un serveur de staging en vue de l'évaluation par l'équipe pédagogique (ratheilesse, primearwyn, MaryseGAHOU), suivez scrupuleusement les étapes suivantes[span_38](end_span):

Étape 1 : Clonage du dépôt distant

git clone https://github.com/votre-compte/projet-mentorat-ifri.git
cd projet-mentorat-ifri

Étape 2 : Configuration de l'environnement virtuel et dépendances

python -m venv venv
source venv/bin/activate # Sur Windows: venv\Scripts\activate
pip install -r requirements.txt

Étape 3 : Configuration de la Base de Données MySQL

Créez une base de données nommée mentorat_ifri sur votre serveur MySQL local, puis configurez le fichier settings.py de Django avec vos identifiants SQL. [span_39](start_span)Appliquez ensuite les migrations pour monter les tables[span_39](end_span):

python manage.py makemigrations
python manage.py migrate

Étape 4 : Lancement du serveur d'application

python manage.py runserver
[span_40](start_span)

L'application sera alors accessible localement à l'adresse internet : http://127.0.0.1:8000/[span_40](end_span).

6. MANUEL D'UTILISATION DE L'APPLICATION

6.1 Parcours Utilisateur initial : Inscription et Configuration

    [span_41](start_span)
  1. Étape de bienvenue : Lancez l'application dans votre navigateur[span_41](end_span). [span_42](start_span)Sur la page d'accueil, cliquez sur le bouton "S'inscrire"[span_42](end_span).
    2. [span_43](start_span)
  2. Création du compte : Remplissez tous les champs obligatoires[span_43](end_span). [span_44](start_span)Prenez soin de saisir une adresse e-mail valide et un numéro de téléphone unique[span_44](end_span). [span_45](start_span)Cliquez sur valider[span_45](end_span).
    3. [span_46](start_span)
  3. Définition du Profil : Accédez à votre tableau de bord puis cliquez sur "Mon Profil"[span_46](end_span). [span_47](start_span)Renseignez votre filière (ex : Génie Logiciel) et votre niveau[span_47](end_span). [span_48](start_span)Ajoutez vos Points Forts (les matières que vous maîtrisez) et vos Points Faibles (les cours où vous éprouvez des difficultés)[span_48](end_span). 6.2 Utilisation du Matching et de la Messagerie

    [span_50](start_span)
  1. Publier une Annonce : Allez dans l'onglet "Annonces"[span_50](end_span). [span_51](start_span)Cliquez sur "Créer une annonce"[span_51](end_span). [span_52](start_span)Choisissez le type (Offre si vous voulez être mentor, Demande si vous cherchez de l'aide), sélectionnez le cours concerné, indiquez vos tranches horaires libres et choisissez le format d'échange (En ligne ou Présentiel)[span_52](end_span).

  3. Entrer en Contact : Cliquez sur le profil d'un étudiant suggéré pour ouvrir une session de chat[span_55](end_span). [span_56](start_span)Vous pouvez lui envoyer un message textuel instantané pour planifier votre première séance d'entraide[span_56](end_span). [span_57](start_span)Une notification visuelle apparaîtra dès qu'il vous répondra[span_57](end_span).
